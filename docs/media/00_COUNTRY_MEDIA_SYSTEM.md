# Country Media Production System

This is the operating guide for generating and integrating premium country visuals for Cultural Currency Converter.

The system is deliberately split into **one country document per country**. AI-assisted work should load this file plus the selected country file, not the entire 30-country prompt library.

## Goals

Generated visual work should make the product feel:

- premium and editorial rather than like a template or stock-photo site;
- realistic and culturally grounded rather than cartoonish;
- consistent across countries while preserving local character;
- useful to the product hierarchy rather than decorative noise;
- transparent about synthetic imagery and careful not to imply documentary evidence.

## Source files

- [Country index](01_COUNTRY_INDEX.md) — all 30 countries, codes, currencies and prompt-file links.
- `countries/<iso2>-<country>.md` — canonical prompts and generation log for one country.
- [Country visual folder guide](../../static/images/country-media/README.md) — repository-tracked visual outputs; filesystem presence is not runtime publication.

## Canonical asset set per country

Each curated country has six prompt IDs.

| ID | Role | Ratio | Target use | Production/design location |
| --- | --- | --- | --- | --- |
| P01 | Hero Wide | 16:9 | destination/editorial atmosphere | production media |
| P02 | Everyday Value | 4:5 | local-value/everyday context | production media |
| P03 | Payment Culture | 4:5 | payment-context supporting visual | production media |
| P04 | Local Detail | 3:2 | editorial supporting/detail image | production media |
| P05 | Desktop Interface Concept | 16:10 | design reference only | docs assets |
| P06 | Mobile Interface Concept | 9:16 | design reference only | docs assets |

Historical imagery is **not** generated by this workflow. Historical surfaces should use authentic archival/institutional material with provenance.

## Premium visual hierarchy

Use these priorities for every country:

1. **Premium first** — composition, materials, light and restraint should make the image feel expensive before any national cue is noticed.
2. **Authentic second** — the environment should remain culturally and physically plausible.
3. **Iconic only third** — landmarks and instantly recognizable symbols are optional supporting cues, not the primary strategy.

### Atmosphere over symbols

Country identity should come primarily from light/weather, material and architecture, transport/street rhythm, café/market/retail/payment behaviour, spatial density and restrained country-specific color notes.

Do not make flags, landmark checklists, national costumes, souvenir objects or tourism shorthand carry the image.

### Premium realism standard

Across P01–P04, prefer:

- natural or cinematic available light;
- realistic lens perspective and architectural geometry;
- controlled depth of field rather than extreme synthetic bokeh;
- subtle filmic depth rather than plastic sharpness;
- incidental human gestures instead of posed stock-photo behaviour;
- material texture that survives close inspection;
- clean hands, faces, devices, tableware and signage;
- one clear visual story per image;
- enough negative space to keep the product calm.

The best image should look **observed rather than generated**.

## Prompt assembly

For a generation run, compose the prompt in this order:

1. **Global Premium Image Contract** below.
2. the relevant **Role Contract** below.
3. the country-specific P01–P06 prompt body from that country's file.

This keeps country files focused while ensuring every generation shares one art direction.

### Global Premium Image Contract

> Create a photorealistic, world-class editorial visual for Cultural Currency Converter, a premium travel-finance product. The result should feel credible beside the best international design, travel and financial editorial work—not like stock photography, a tourism campaign, a generic AI image or a template. The visual language is quiet, sophisticated and contemporary: realistic materials, believable human scale, natural or cinematic available light, restrained saturation, nuanced contrast, subtle filmic depth, excellent composition, and a refined warm-neutral grade. It should feel closer to Monocle, Kinfolk, a premium financial product campaign, or an international design magazine than to a tourism brochure. Cultural identity should come from authentic place, architecture, objects, food, transit, retail and everyday behaviour rather than flags or stereotypes. Preserve negative space for product UI where the role calls for it. Avoid cartoon styling, flat illustration, 3D toy aesthetics, fantasy, excessive HDR, neon oversaturation, tourist-postcard composition, flag-dominant scenes, national-costume clichés, staged corporate stock photography, fake luxury props, obvious AI symmetry, distorted hands, malformed objects, unreadable signage as a focal point, watermarks and logos. Do not fabricate documentary or historical evidence. The image should look plausible enough to sit inside an expensive real product.

### P01 — Hero Wide contract

> 16:9 landscape. Establish a strong sense of place through one coherent contemporary scene. Prefer a believable 35–50 mm full-frame-equivalent editorial perspective, realistic architectural lines and medium depth. Use a clear focal plane plus layered depth, subtle human presence where natural, and enough calmer negative space for adjacent UI. No collage. No landmark checklist. The country should be recognizable through atmosphere rather than literal symbols.

Recommended production target: `1920×1080` WebP.

### P02 — Everyday Value contract

> 4:5 portrait editorial photography. Show one believable everyday spending context at human scale, usually with a natural 50–70 mm observational feel: café, bakery, casual meal, transit, market or small retail depending on the country prompt. The image supports the idea of local value but must not show or imply an exact current price unless the price is separately sourced in product data. Focus on tactile detail, natural behaviour and premium composition rather than staged advertising.

Recommended production target: `1200×1500` WebP.

### P03 — Payment Culture contract

> 4:5 portrait editorial photography. Show a believable payment moment in context. The payment gesture is supporting evidence of atmosphere, not the whole picture; roughly 20–30% of the visual story is enough. The transaction should be visually legible but subtle: card, phone, QR or cash only where appropriate to the country-specific prompt. Avoid visible real financial-app logos, fake bank branding or a technology-demo look. This is illustrative atmosphere, not evidence that every merchant or person pays this way.

Recommended production target: `1200×1500` WebP.

### P04 — Local Detail contract

> 3:2 landscape editorial detail. Build a sophisticated still-life or close observational scene with a 65–85 mm close-editorial feel, tactile side-light and only two to four meaningful elements from locally credible materials, objects, transport cues, café/market details or street texture. It should work as an atmospheric supporting image with minimal visual clutter and no souvenir-shop feel.

Recommended production target: `1500×1000` WebP.

### P05 — Desktop Interface Concept contract

> 16:10 desktop product-design concept. Show Cultural Currency Converter as a premium editorial financial interface that looks plausible enough to ship. It must not resemble a fantasy Dribbble concept. on a warm ivory/stone canvas with deep forest accents, restrained metallic-warm secondary accents, generous whitespace, strong numeric hierarchy and a bilateral source/destination composition. The conversion result is the dominant visual moment. Integrate one country photograph subtly rather than turning the screen into a travel collage. Keep visible text extremely limited and short: country name, currency code, amount, result, “Cultural Currency”. Do not invent dense copy. No glassmorphism, neon gradients, crypto-dashboard styling or generic SaaS card soup. This is a design reference, not a shippable screenshot.

Recommended reference target: `1920×1200` WebP under docs assets.

### P06 — Mobile Interface Concept contract

> 9:16 mobile product-design concept for Cultural Currency Converter. Use a realistic modern viewport, safe-area spacing and believable tap targets; no decorative phone frame. Preserve the same premium editorial-finance visual language as the desktop concept: calm ivory/stone surfaces, deep forest accent, large monetary result, compact source/destination control, excellent spacing, one subtle country image and minimal copy. Respect realistic mobile ergonomics and safe areas. Avoid tiny dashboard widgets, excessive pills, glassmorphism and fake operating-system chrome. This is a design reference, not a production screenshot.

Recommended reference target: `1080×1920` WebP under docs assets.

## Generation workflow

### 1. Pick exactly one asset

Open:

- this production-system document;
- the selected country's file.

Select one P01–P06 prompt.

Generate **one image per iteration**. Do not batch multiple countries or roles into one generation request.

### 2. Review before committing

Score the candidate on:

- premium visual quality;
- realism / physical plausibility;
- country specificity without stereotype;
- composition and crop;
- lighting and grading;
- product usefulness;
- absence of AI artefacts;
- consistency with the rest of the collection.

A candidate should normally score at least **90/100 overall** and have no serious authenticity, anatomy, signage or composition issue before it is approved.

### 3. Reject without polluting Git history

Do not commit rejected candidates just to preserve them. Regenerate locally/in the generation session.

Only an approved version receives the canonical repository filename.

### 4. Version deterministically

First approved attempt:

`v01`

A later intentional replacement:

`v02`

Do not overwrite an already published version silently. If the new image supersedes it, add the new version, update references, then remove the old asset in the same change when appropriate.

### 5. Record the generation

Update the **Generation Log** in the country's documentation with:

- prompt ID;
- version;
- generation date;
- generator/model if known;
- repository path;
- status;
- short review note.

### 6. Optimize

Before production use:

- crop to the role's intended ratio;
- export to high-quality WebP;
- remove unnecessary metadata;
- verify dimensions;
- visually inspect at desktop and mobile sizes;
- add meaningful alt text when the image is informative.

### 7. Publish deliberately

Generated imagery must remain transparently classified as generated/synthetic in media metadata when imported into the managed media system.

Do not use generated visuals as historical evidence, a source for prices, or proof of payment behaviour.

## Production vs design-reference boundary

P01–P04 may become production atmosphere/supporting media after review and after the product's media-selection policy allows that generated role.

P05–P06 stay in documentation. The real interface is always HTML/CSS/TypeScript/Django templates, not a generated screenshot.

## AI-assisted workflow

When asking an AI agent to continue this work, prefer a narrow instruction such as:

> Read `docs/media/00_COUNTRY_MEDIA_SYSTEM.md` and `docs/media/countries/fi-finland.md`. Generate P01 only. Do not modify other country prompts.

This keeps context small and makes the result reproducible.

## Completion definition

A country media pack is **core-complete** when P01–P04 each have one approved prompt output and the generation log is current. This describes the media-production pack, not runtime publication status.

A country media pack is **showcase-complete** when P01–P06 are approved. Runtime eligibility is still governed by managed-media review/publication rules and the role-specific authenticity policy.

1. Finland
2. Japan
3. France
